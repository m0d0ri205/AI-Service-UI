# AI service UI

### 1. 프로젝트 개요

프로젝트 소개 및 4단계 워크플로우 설명
개발 배경 (현대 웹 생태계의 보안 문제점, 기존 솔루션의 한계)
프로젝트 목표 (자동화, AI 분류, UI, 실시간 피드백, 로컬 처리)

### 2. 시스템 아키텍처

5개 핵심 컴포넌트 상세 설명
Tkinter UI, MCP Client, Kali Server, AI Model, Verification Module
7단계 데이터 흐름도

### 3. UI 구현 및 사용자 인터페이스

UI 설계 4대 원칙 (단순성, 일관성, 피드백, 접근성)
메인/Input/History/Specifications 화면 상세 설명
사용자 경험 최적화 방안

### 4. 서비스 구동 시나리오 ⭐

Phase 1: 입력 및 초기 분석 (프롬프트 생성 과정 포함)
Phase 2: MCP 기반 취약점 분석 (Kali 도구 실행 및 시나리오 생성)
Phase 3: AI 공격 유형 예측 (전처리, 특징추출, 추론, 후처리)
Phase 4: 취약점 검증 및 리포트 생성

### 5. 주요 소스 코드 설명

UI 컴포넌트 주요 클래스/함수
MCP 연동 모듈 구조
AI 모델 인터페이스
취약점 검증 엔진

### 6. AI 모델 구현 및 평가 ⭐
-> 
사용한 신경망 모델: BERT 기반 Transformer (110M 파라미터)
학습 데이터셋: 15,000개 샘플 (10가지 공격 유형)
모델 학습 과정: 전처리, 초기화, 학습 루프, 검증
성능 평가: Accuracy 89.3%, F1-Score 88.3%, 클래스별 상세 성능

한계점 및 개선사항
향후 계획 (지속적 학습, 자동 패치, CI/CD 통합, 협업 기능)
